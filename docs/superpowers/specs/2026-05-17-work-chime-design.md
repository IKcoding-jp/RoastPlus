# 作業チャイム デザイン仕様

## 背景

RoastPlus の時計機能は、職場の iPad を現場に置き、複数人が離れた場所から時刻を確認する用途で使われている。
現状の時計は大きな時刻、日付、曜日を表示できており、遠距離視認性はすでに十分ある。

追加する価値は、単なる時計表示ではなく、休憩開始・作業開始の区切りを現場全体に共有することにある。

## 採用方針

通常時は既存の時計表示を崩さず、下部に現在の時間帯と次の区切りを控えめに表示する。
チャイム時は音に加えて、中央に大きな通知パネルを表示する。

既存の時計機能から見た目を大きく変えず、`DESIGN.md` の「集中操作 / 実行」画面として扱う。
派手なポスター風デザインや装飾的な演出は使わない。

## 通常時表示

時計画面は現行の構成を維持する。

- 大きな時刻表示
- 秒表示
- 日付・曜日表示
- アクセントライン
- 左上の戻るボタン
- 右上の設定ボタン

追加表示:

```text
現在 09:00-10:30 作業中
次 10:30 休憩開始
あと 12分
```

表示位置は時計下部。
既存の時刻表示を邪魔しないよう、控えめなピル型または細いパネルとして表示する。

## チャイム時表示

チャイム時は背景の時計を薄く残し、中央に通知パネルを重ねる。
通知パネルは白系の背景、控えめな影、細いアクセントラインで構成する。

休憩時:

```text
10:30 休憩開始
休憩時間です
```

作業開始時:

```text
10:45 作業再開
作業開始です
```

表示ルール:

- メイン文言は1行表示を基本にする
- 説明文は入れない
- 遠くから読むべき情報は「休憩時間です」「作業開始です」に絞る
- 時刻ラベルはメイン文言より小さく表示する
- 閉じるボタンは右上に小さく薄く表示する

## 色

既存の時計テーマを基本にする。
通知パネルのアクセントだけ、状態に応じて切り替える。

- 作業開始: オレンジ系アクセント
- 休憩: グリーン系アクセント
- 掃除開始: ニュートラル系アクセント

色だけに依存せず、文言でも状態を明確にする。

## 音

チャイム時は音を鳴らす。
iPad / Safari の自動再生制限を考慮し、設定モーダル内に「音を有効化」操作を用意する。
時計画面の中央には、有効化用の大きなボタンを出さない。

初期採用する音は、モック `.superpowers/brainstorm/work-chime-sound-options.html` の **A. やわらかい現場チャイム** とする。
チャイム時刻は、単独の時刻リストではなく、作業・休憩の時間帯設定から算出する。

音の意味:

- 休憩開始: 少し下がる2音。落ち着いて作業を区切る印象にする
- 作業開始 / 作業再開: 少し上がる3音。再開が分かる印象にする

初期実装では、音声アナウンスはOFFにする。
音声は人によって「指示されている」印象や違和感が出る可能性があるため、デフォルトでは使わない。

音声設定:

- 作業チャイム ON/OFF
- 音 ON/OFF
- 音量
- 音声アナウンス ON/OFF（初期値OFF）

作業・休憩・掃除時間帯は時計設定モーダルに混ぜず、時計設定アイコンの左に置く専用の「チャイム時刻設定」アイコンから開く。
チャイム時刻設定では、開始時刻、終了時刻、種別（作業 / 休憩 / 掃除）を編集できる。

音声アナウンスをONにした場合の文言候補:

```text
10時30分です。休憩時間です。
10時45分です。作業開始です。
```

音声は初期実装ではブラウザ内蔵音声ではなく、将来的にGoogle TTS等で事前生成した音声ファイルを使う想定にする。
ただし、初期リリースで音声ファイルを同梱する必要はない。

## 時刻設定

作業時間と休憩時間は現在固定運用だが、今後の変更に対応できるように、コード固定ではなく設定できる形にする。

最初の範囲:

- 毎日共通の区切り時刻
- 時刻
- 種類: `休憩開始` / `作業開始` / `作業再開`
- 表示名

最初は曜日別設定やシフト別テンプレートは作らない。
必要性が出た場合に追加する。

## 表示時間

チャイム表示は自動で消える。

- 5秒表示
- 手動で閉じることもできる

初期実装では固定値 5 秒で始める。

## 非スコープ

初期実装では以下を含めない。

- 曜日別チャイム
- シフト別テンプレート
- Firestore同期
- 管理者による一括配信
- 担当表やスケジュールとの連携
- 音声読み上げ
- 複雑なアニメーション

## UX上の注意

- 通知は目立たせるが、時計画面の延長として見えること
- AIっぽいグラデーション、過度な装飾、ポスター風の見た目は避ける
- 現場の2つのテーブルから見えるよう、メイン文言は十分大きくする
- 補足説明は増やさない
- 通常時の時計視認性を落とさない

## 参照モック

採用モック:

```text
.superpowers/brainstorm/work-chime-clock-aligned.html
```

採用状態:

- 通常時タブ
- 休憩チャイムタブ
- 作業開始チャイムタブ

このモックのうち、最終採用する表示は「現行時計準拠」のタブ式案。
チャイム時の説明文は削除し、大きな本文＋時刻ラベルだけにする。

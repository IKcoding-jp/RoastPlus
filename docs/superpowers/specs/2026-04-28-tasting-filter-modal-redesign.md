# フィルターモーダル UI 改善仕様書

**作成日**: 2026-04-28  
**対象ファイル**: `components/TastingSessionFilterModal.tsx`, `components/ui/Button.tsx`

---

## 概要

試飲記録ページのフィルターモーダルのUIを改善する。現行の問題点（縦並びボタン・ghost variant の見た目のちぐはぐさ）を解消し、RoastPlus のデザインシステムと統一感のある洗練されたUIに刷新する。

---

## 現行の問題点

| 問題 | 原因 |
|------|------|
| 並び替えボタンが縦3列でスペースを無駄遣い | `grid-cols-1` の Button コンポーネント |
| 非選択の ghost ボタンがオレンジテキストのみで選択肢に見えない | `variant="ghost"` はリンク風スタイルで、選択肢 UI 向けではない |
| 焙煎度合いの未選択チップが ghost でスタイルが統一されていない | 同上 |
| フッターが「リセット + キャンセル + 適用」の 3 要素で散漫 | レイアウト設計の問題 |
| モーダルのスクリムが薄い | `bg-black/20` は Modal 背景として弱い |

---

## デザイン決定事項

### 1. モーダルヘッダー — ダークブラウン化

```
Before: bg-overlay（白）
After:  bg-[#261a14]（ダークブラウン = --header-bg と同値）
```

- アプリのナビゲーションバーと同じ `#261a14` を使用
- タイトルテキスト: `text-white`
- アイコンピル背景: `rgba(255,255,255,0.12)`（半透明白）
- アイコンストローク: `#EF8A00`（ブランドオレンジ = `--primary`）
- 閉じるボタン: `rgba(255,255,255,0.10)` 背景 + 半透明白 × アイコン

### 2. ヘッダー右上にリセットボタンを配置

```
Before: フッター左端に「フィルターをリセット」テキストリンク（独立行）
After:  ヘッダー右上「リセット」テキスト ＋ その右に「×」ボタン
```

- リセットは `color: rgba(255,255,255,0.5)` のテキストリンク
- アクティブなフィルターがない場合は `hidden`（現行と同じ条件）
- 閉じる（×）ボタンは常に表示

### 3. 並び替えセクション — 縦ボタン → 横3列チップ

```
Before: grid-cols-1 × Button variant="primary/ghost"
After:  grid-cols-3 × 専用チップスタイル
```

**チップスタイル（Button コンポーネントに `variant="chip"` を追加）:**

| 状態 | スタイル |
|------|---------|
| 未選択 | `bg-ground border border-edge text-ink-sub` |
| 選択中 | `bg-spot text-white border-spot shadow-sm` |

`min-h` は `min-h-[36px]` に変更（通常の 44px より低いが、グリッド内の補助的操作のため許容）。

### 4. 焙煎度合いセクション — flex-wrap → 4列グリッド

```
Before: flex flex-wrap gap-2 × Button variant="coffee/ghost" size="sm"
After:  grid grid-cols-4 gap-1.5 × variant="chip" size="sm"
```

**選択状態の色分け:**

| 状態 | スタイル |
|------|---------|
| 未選択 | `bg-ground border border-edge text-ink-sub` |
| 選択中 | `bg-[#261a14] text-[#f5c89a] border-[#261a14]`（既存 coffee バリアントと同色） |

> 焙煎度の選択状態はコーヒーらしいダークブラウン地+琥珀テキストを維持する。

### 5. フッター — 2ボタンに簡素化

```
Before: [リセット行] + [キャンセル] [適用]
After:  [キャンセル] [適用] のみ（リセットはヘッダーへ移動）
```

### 6. スクリム強化

```
Before: bg-black/20
After:  bg-black/40
```

## 実装範囲

### `components/ui/Button.tsx`

**変更なし。** Button の `baseStyles` に `min-h-[44px]` が固定されているため、コンパクトなチップ UI には不適。FilterModal 内でネイティブ `<button>` + Tailwind クラスを直接使う（Button コンポーネントを経由しない）。

> 将来的にチップパターンが複数箇所で使われるようになったら、その時点で `variant="chip"` または専用 Chip コンポーネントに抽出する。今回は YAGNI。

### `components/TastingSessionFilterModal.tsx`

1. モーダル外枠のスクリムを `bg-black/20` → `bg-black/40` に変更
2. ヘッダーを `bg-[#261a14]` に変更し、タイトル・アイコンの色を調整
3. ヘッダー右側に `リセット` テキストボタン（条件付き表示）＋ 閉じるボタンを配置
4. 並び替えセクションを `grid grid-cols-3` のチップに変更
5. 焙煎度合いセクションを `grid grid-cols-4` のチップに変更
6. フッターからリセットボタン行を削除し、キャンセル・適用のみに

## 非変更事項

- 検索インプット（デザイン・動作ともに変更なし）
- 日付範囲（デザイン・動作ともに変更なし）
- フィルターロジック・状態管理（`useTastingFilters` hook は触らない）
- モーダルのアニメーション（scale + fade は現行維持）

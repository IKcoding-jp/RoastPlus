比較メモ

A案: 優先カード + その他一覧 おすすめ

現場で毎日使う機能を大きく残し、頻度が低いものは1行リストへ落とす。押しやすさと項目増加への耐性のバランスが良い。

B案: 全部1行リスト 採用候補

項目数が増えても崩れにくく、ユーザーがカテゴリを考えずに上から探せる。スマホでは説明文を消し、アイコン + 機能名だけにして1画面内に収める。

C案: カテゴリ分け 保留

カテゴリで意味を残しつつ、4列の小タイルで縦幅を抑える。機能が増えても、カテゴリ追加や並び替えで整理しやすい。

要件定義で決めたいこと

  1. スマホで最初に大きく出す「よく使う機能」を4件に固定するか。
  2. ユーザーのホーム表示設定を、優先表示にも使うか。
  3. 「開発秘話」「クイズ」など日常業務外の項目を下位に回してよいか。
  4. 390px × 844px 前後のスマホで、機能一覧を1画面内に収める。

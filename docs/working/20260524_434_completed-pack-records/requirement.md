# Requirement: Issue #434 パッケージ数記録機能を追加する

## 目的

A班・B班ごとのパッケージ数をRoastPlusに記録し、Mさんに依存せずに当日の生産数を確認できるようにする。

## 背景

現在は紙やホワイトボードでパッケージ数を記録しており、記録・集計・確認がMさんに属人化している。
A班・B班それぞれで成功数・失敗数を記録し、合計はアプリ側で自動計算したい。

## スコープ

### 含む

- 作業日ごとのパッケージ数記録
- A班 成功数 / 失敗数
- B班 成功数 / 失敗数
- 成功合計、失敗合計、総数の自動計算
- 「保存」ボタンによる保存
- 今日以前の日付の追加・修正
- 当日分の削除
- 過去日の記録一覧の閲覧
- A班用・B班用iPadで同じ作業日の記録を同期表示

### 含まない

- 管理者権限
- 承認フロー
- 在庫管理
- 発送管理
- 持ち帰り管理
- 製造月・前半/後半の紐づけ

## 入力項目

- 作業日
- A班 成功数
- A班 失敗数
- B班 成功数
- B班 失敗数

## 自動計算

- 成功合計 = A班成功 + B班成功
- 失敗合計 = A班失敗 + B班失敗
- 総数 = 成功合計 + 失敗合計

## 受け入れ条件

- [ ] A班/B班の成功数・失敗数を保存できる
- [ ] 保存後に成功合計・失敗合計・総数が表示される
- [ ] 別端末でも同じ日の記録が同期表示される
- [ ] 今日以前の日付の記録を追加・修正できる
- [ ] 当日分のみ削除できる
- [ ] 過去日の記録を一覧で確認できる

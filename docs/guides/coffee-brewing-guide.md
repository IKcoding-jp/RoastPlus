## 基本レシピ（2人分）

※1番バランスの良い美味しいレシピ

- お湯の温度は **92度**
- ペーパーをセットする
- ドリッパーにお湯をかけて温める
- 粉は **20g**（2名分）
- お湯を **20g** かけて **20秒蒸らす**
- 注湯は **180ml → 80ml → 40ml** の3投
- 湯面が **1cm 下がったら** 次のお湯を入れる
- 全体で **3分〜3分半** で完了
